Frequently Asked Questions

What is an image color picker?

An image color picker lets you select a pixel from an image and retrieve its color values, such as HEX, RGB and HSL.

What is the difference between HEX, RGB and HSL?

HEX represents a color with a hexadecimal code. RGB describes its red, green and blue components. HSL describes hue, saturation and lightness.

Are my images uploaded to a server?

No image upload to a DigiiFox server is required. The image is read and processed in your browser. The image itself is not intentionally sent to our server by this tool.

Which image formats are supported?

The tool accepts common formats including PNG, JPEG, WebP, GIF, BMP and AVIF when supported by your browser. Animated images are sampled as they are decoded by the browser, typically using their displayed frame.

Can I save the colors I pick?

Yes. Recent colors stay available while the page is open. You can also download the current palette as a text file.

Why might a color look different on another screen?

Screen calibration, image color profiles, display settings and color management can affect how colors appear. The displayed values represent the sampled pixel values decoded by your browser.
