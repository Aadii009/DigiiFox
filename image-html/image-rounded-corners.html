Frequently Asked Questions

How can I round the corners of a photo?

Upload your image, adjust the Corner Roundness slider, review the preview, and download the result.

Can I make the corners transparent?

Yes. Enable Transparent Corners and export as PNG or WebP. JPG does not support transparency, so it uses the selected background color instead.

Can I change the background color?

Yes. Turn off Transparent Corners and select a color using the color picker or enter a hexadecimal color code.

Will the image dimensions change?

No. The output keeps the original image width and height. The corners are rounded within those dimensions.

Which formats can I use?

You can upload JPG, PNG and WebP files and download the result in PNG, JPG or WebP format.

Are my images uploaded to a server?

No. The image is processed locally in your browser and is not uploaded to a DigiiFox server by this tool.

Does rounding corners reduce image quality?

The rounded shape is created at the image's original dimensions. PNG is lossless, while JPG and WebP use the selected compression quality.
