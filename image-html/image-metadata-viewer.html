Frequently Asked Questions

What is image metadata?

Image metadata is information stored in or associated with an image file. It may include dimensions, capture date, camera model, exposure settings, orientation and location information.

Why is some EXIF information missing?

Not every image contains EXIF metadata. Screenshots, edited images and images shared through some messaging or social platforms may have metadata removed. This tool displays information it can detect in the selected file.

Can I see where a photo was taken?

If the image contains GPS coordinates, the tool can display them. Many images do not contain location metadata, so a missing GPS section does not mean the photo has no known location.

Does viewing metadata change my image?

No. This tool reads the selected image and displays its properties. It does not modify the original file.

Are my images uploaded to a server?

The image is processed locally in your browser and is not intentionally uploaded to a DigiiFox server. The metadata library is downloaded from a third-party CDN, so an internet connection is required unless the library is hosted locally.

Can I edit or remove metadata here?

This is a viewer, not a metadata editor. It displays available information and can export a text report, but it does not alter or remove metadata from your image.
