    UNDERSTANDING PROBABILITY

    What Is Probability?

    Probability measures how likely an event is to happen. It ranges from 0 to 1, or from 0% to 100%. A probability of 0 means an event is impossible, while a probability of 1 means it is certain under the model being considered.

    Basic Probability Formula
    P(E) = F/N

    F = favorable outcomes and N = total equally likely outcomes.

    Example: Rolling a Die

    A standard six-sided die has six equally likely outcomes. Only one outcome shows a 4.

    P(rolling a 4) = 1/6
    ≈ 0.1667 = 16.67%

    Important Probability Formulas

    Single event P(A) = Favorable outcomes / Total outcomes, for equally likely outcomes.
    Complement P(not A) = 1 − P(A)
    Independent events P(A and B) = P(A) × P(B)
    Mutually exclusive events P(A or B) = P(A) + P(B)

    Important: The basic favorable-outcomes formula requires equally likely outcomes. The combined formulas also require the stated conditions: independence for multiplication and mutual exclusivity for simple addition.

    COMMON QUESTIONS

    Frequently Asked Questions

    What is probability?

    Probability measures the likelihood of an event. It ranges from 0 to 1, or 0% to 100%.

    How do I calculate basic probability?

    For equally likely outcomes, divide the number of favorable outcomes by the total number of possible outcomes.

    What is the probability of an impossible event?

    An impossible event has probability 0, or 0%.

    What is complementary probability?

    It is the probability that an event does not occur. Calculate it using 1 − P(A).

    When can I multiply two probabilities?

    For independent events, the probability that both occur is P(A) × P(B). Dependent events require conditional probability instead.

    When can I add two probabilities?

    For mutually exclusive events, the probability that either occurs is P(A) + P(B). For events that can overlap, subtract P(A and B) from the sum.

    Why is probability shown as a percentage?

    Multiplying a probability decimal by 100 converts it to a percentage. For example, 0.25 equals 25%.

    Probability Basics

    Impossible 0%

    Equally likely 50%

    Certain 100%

    Useful Formulas

    Single event P(A) = F/N
    Complement P(A') = 1 − P(A)
    Independent events P(A ∩ B) = P(A)P(B)
    Mutually exclusive events P(A ∪ B) = P(A) + P(B)
