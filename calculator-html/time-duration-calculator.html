UNDERSTAND THE MATH

What is a Time Duration Calculator?

A Time Duration Calculator finds the elapsed time between a starting point and an ending point. It can help calculate work shifts, study sessions, travel time, event lengths, and more.

ƒ

Basic formula

Duration = End time − Start time

When the end point is on the next day, the date difference is included before calculating the elapsed time.

↔

Convert time units

Hours = Seconds ÷ 3,600

Convert a duration into minutes by dividing seconds by 60, or into days by dividing seconds by 86,400.

◷

Clock format

HH:MM:SS

The result also uses hours, minutes, and seconds in a clock-style format for easy reading.

COMMON QUESTIONS

Frequently asked questions

Can I calculate a duration across midnight?

Yes. Leave both dates blank and enter an end time earlier than the start time. The calculator treats the end time as occurring on the next day.

Can I calculate a duration across several days?

Yes. Select both the start date and end date, then enter the times. The calculator uses the selected dates to determine the elapsed duration.

What if the start and end times are identical?

With no dates selected, identical times produce a duration of zero. If you select dates, the date range determines the duration.

Are my entered dates and times uploaded?

No. The calculation runs in your browser. This page does not need to upload your entries to a server.
