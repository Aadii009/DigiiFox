UNDERSTANDING THE TOOL

What Is a Days Between Dates Calculator?

A Days Between Dates Calculator finds the number of calendar days between two dates. Depending on the counting method, it can calculate elapsed days or count both the start and end dates inclusively.

The tool can also show complete weeks, remaining days, weekdays, and weekend days. It is useful for calculating deadlines, trip durations, event periods, and other date ranges.

FORMULA & LOGIC

Formula Used

01

Elapsed Days

End date − Start date

The start date is excluded.
02

Inclusive Days

Elapsed days + 1

Both dates are counted.
03

Complete Weeks

⌊ Total days ÷ 7 ⌋

Any remainder is shown separately.
04

Weekdays

Total counted days − Weekend days

Weekdays are Monday through Friday.
Important: The inclusive option changes the count by one day when both dates are the same or when the range spans multiple days. Weekdays and weekend days use the same selected counting convention.

COMMON QUESTIONS

Frequently Asked Questions

How do I calculate the days between two dates?

Select the start and end dates and click Calculate Days. The calculator subtracts the earlier date from the later date to determine the elapsed calendar days.

What is the difference between inclusive and elapsed days?

Elapsed days measure the time between dates and exclude the starting date. Inclusive counting includes both the start and end dates, so it adds one day to the elapsed count.

Does it account for leap years?

Yes. Actual calendar dates are used, so February 29 is included in the calculation whenever it occurs within the selected period.

Can I calculate dates in reverse order?

Yes. The calculator automatically orders the dates chronologically and returns a non-negative difference.

Are public holidays excluded from weekdays?

No. Weekdays include Monday through Friday, even if one of those days is a public holiday. The calculator does not use a country-specific holiday calendar.

Does one week always equal seven days?

Yes. Complete weeks are calculated by dividing the selected day count by seven and taking the whole-number result. Remaining days are displayed separately.

Is this calculator free to use?

Yes. All calculations run in your browser, and you do not need an account or backend service to use it.
