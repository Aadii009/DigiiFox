NEED HELP?

Frequently Asked Questions

Find answers to common questions about adding page numbers to PDFs.

How do I add page numbers to a PDF?

Upload your PDF, select your preferred numbering settings, and click Add Page Numbers. Your updated file will download when processing finishes.

Can I choose where page numbers appear?

Yes. You can place numbers at the top or bottom of the page, aligned to the left, center, or right.

Can I start numbering from a number other than 1?

Yes. Enter your preferred starting number in the Starting number field. The selected pages will then be numbered sequentially from that value.

Can I number only selected pages?

Yes. Enter page numbers and ranges separated by commas, such as 1-3, 5, 8-10. Leave the field empty to number every page. Page ranges refer to the PDF's existing page positions.

Does this tool upload my PDF?

No. The PDF data is processed in your browser and is not uploaded to a DigiiFox server. The PDF library itself is downloaded from a third-party CDN, so using the tool requires an internet connection to load that library.

Will adding page numbers change my original PDF?

No. The tool creates and downloads a separately numbered PDF. Your original file is not overwritten.

Can I use this tool on a password-protected PDF?

This version does not unlock encrypted PDFs. You may need to open and export an accessible, unencrypted copy before using the tool.

Is the Add Page Numbers tool free?

Yes. You can use this DigiiFox tool to add page numbers without paying for this feature.
