Frequently Asked Questions

Is DigiiFox Merge PDF free?

Yes. This version of the tool is free to use.

Are my PDF files uploaded?

The merging code runs in your browser and does not send selected PDF contents to a DigiiFox server. The page does load a PDF library from a CDN, so the browser makes a network request to load that library.

Can I change the order of the PDFs?

Yes. Use the up and down arrow buttons next to each file.

Will my original files change?

No. The tool creates a new merged PDF and leaves your original files unchanged.
