Your privacy matters

Your selected PDF is processed locally in your browser. DigiiFox does not upload the document to its own server. The PDF-Lib library is loaded from a third-party CDN, so an internet connection is required to load the tool.

How to Use the PDF Metadata Editor

  1. Select a PDF file from your device.
  2. Review the document information displayed in the form.
  3. Edit the title, author, subject, keywords, or other available fields.
  4. Select “Save and Download PDF” to export the updated document.

Frequently Asked Questions

What is PDF metadata?

Metadata is information stored in a PDF, such as its title, author, subject, and keywords.

Will editing metadata change the document's content?

This tool edits standard document information. It does not provide a way to edit the visible text or images on PDF pages.

Does this tool upload my PDF?

No. The PDF is processed in your browser. The library needed to run the tool is loaded from a CDN.

Why can't I edit my PDF?

Some PDFs are encrypted, damaged, or use unsupported features. Try an accessible, unencrypted PDF.

Will all PDF metadata be changed?

This tool updates the standard properties shown in the form. Other metadata, digital signatures, and specialized document features may not be preserved exactly.
