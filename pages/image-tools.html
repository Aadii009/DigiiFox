Frequently Asked Questions

Learn more about using the DigiiFox image toolkit.

Are DigiiFox image tools free to use?

The tools are designed for easy online use. Any usage limits or additional service requirements will be explained on the relevant tool page.

Do I need to install any software?

No installation is intended for the browser-based tools. You can open the website in a modern browser. Some advanced features may require an internet connection or an external processing service.

Are my images uploaded to a server?

Tools that process images locally in your browser can avoid sending the image to our server. Advanced features may work differently, so each tool should clearly explain its processing method before you use it.

Which image formats are supported?

Format support varies by tool and browser. Common formats include JPG, PNG, and WebP, while specific tools may support additional formats.

Will converting an image reduce its quality?

It depends on the output format and settings. Lossy formats such as JPG can reduce quality, while PNG can preserve lossless image data. Some format conversions may also change transparency.

Can I use these tools on my phone?

Yes. The Image Tools page is designed to adapt to mobile screens. Individual tools will also be built with responsive layouts where practical.
